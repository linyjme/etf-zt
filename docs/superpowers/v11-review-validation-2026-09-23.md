# V1.1 审查修复与验证记录

## 已实现

- 干净克隆的运行时源码依赖闭包已纳入仓库，模块完整性测试覆盖服务入口。
- 估值统一为 ROE 期间年化、`PE²/(PB×100)` canonical PR、10 年分位优先、过期/缺失状态和不可用阶段。
- V1.1 环境只读取沪深 300 / 中证 1000 证据；缺少类别、数据质量或 T4 证据时 fail-closed。
- 修复周五休市周的周线聚合；`evaluate_v11` 直接调用和服务预计算使用同一扁平指标契约。
- 对齐 T3/T4、A6 MACD/RSI、B1/B2/B6、A/B 互斥、止损 2ATR、E3/E4、S1/S2、R 值和 T+1 规则。
- 估值阶段已接入 V11 证据和页面。阶段行为由 `valuation_stage_enforcement` 显式开关控制，默认关闭，不会绕过任何技术或质量硬门槛。
- 增加 VERIFIED 数据质量门控：250 根已完成日线、最近有效交易日、供应商成交额、元数据、000300/000852 环境历史及完整核验收据缺一不可；所有缺项都有稳定 `DATA_QUALITY_*` 原因码。
- 页面展示质量门控、估值阶段、ROE 期间/一致性和具体阻断原因；所有 V11 决策仍固定 `executable=False`。
- 影子层复用同一质量状态和 `DATA_QUALITY_*` 原因码；持仓风险未知时不再用平均价的 1% 猜测 R，而是标记 `risk_known=false` 并停用动作。

## 当前安全状态

仓库研究清单仍包含估算成交额、`CROSSCHECK_PENDING` 和空的 `source_receipts`。因此服务默认显示 `UNVERIFIED`，只显示观察证据，不生成技术候选、建仓、补仓或持仓动作。这是预期的发布门控结果，需补齐真实供应商收据后才可能转为 `VERIFIED`。

估值阶段行为尚未启用。应先记录至少 5–7 个有效交易日的影子统计，再单独打开配置开关；在此之前不得用阶段调整仓位或利润保护。
