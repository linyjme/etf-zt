# SWING_V11 影子验证记录

日期：2026-09-21

## 结论

SWING_V11_SHADOW 已接入规则模块、服务只读快照、波段页面和影子报告结构，但仍未开放为正式提醒或任何自动执行。当前发布门槛为 **不通过**，不能据此宣称策略收益或建议真实买卖。

## 当前研究数据门槛

本地研究清单 `data/swing/research_manifest.json` 包含 33 个标的：25 个完整样本、8 个短样本。所有标的的成交额均为估算值，交叉核验均为待处理；调整状态为未知或待复核；33 个标的均未达到滚动样本外资格。

因此报告会保留以下阻断码：

- `DATA_QUALITY`：成交额、交叉核验或复权证据尚未完成。
- `WALK_FORWARD`：尚未形成可用的样本外窗口。
- `OOS_WINDOWS`：尚未达到至少两个样本外窗口。
- `V11_SHADOW_ONLY`：V11 只产生判断证据，不产生组合交易。

## V11 输出范围

每个标的的 V11 记录包括：状态、A/B 形态、数据时点、阻断原因、指标证据、计划金额、止损证据和缺失数据计数。`executable` 永远为 `false`，页面明确显示“人工确认”和“不支持自动下单”。
